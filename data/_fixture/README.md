# Fixture data — NOT CLINICAL CONTENT

Synthetic numbers whose only job is to prove the macro validator works. The "foods" are
named TEST BLOCK on purpose so nobody can mistake this for a meal plan.

Nothing in this folder may ever reach a patient, a printout, or `dist/`.
`build-protocol.mjs` refuses to render a patient copy from fixture data.

Run `node build-protocol.mjs --self-test` to exercise it.
