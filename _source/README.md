# _source — practice material only

Everything in this folder comes from Pounds. Nothing in it is written by the agency, and
nothing in it is edited by the agency. It is read-only input.

## What belongs here

- The 1200 kcal / 50-75g carb / 100g protein foundation document
- Current GLP-1 patient education material
- Dosing and timing sheets for KetoCitra, the allulose gummies, the multivitamin, Naked Whey
- Any meal or snack lists already given to patients

## What must never land here

**No patient documents. No charts. No names. No PHI.** If a file has a patient identifier
in it, it does not belong in this repo at all. Clinical education material only.

## Getting the material in

Preferred: Pounds shares the SharePoint document library, it gets synced through the
OneDrive client, and this folder points at it. Fallback: an exported copy dropped in here,
which goes stale and has to be refreshed by hand.

Every food and meal in `data/` names the file here it came from. That traceability is what
makes the protocol reviewable.
